# NyrexDev Portfolio

1. Put your profile picture in `Assets/` named exactly `ProfilePic.png`.
2. Drop project images into `Portfolio/` (png, jpg, jpeg, gif, webp). They show up automatically.
   Images are ordered by file name, so `01-name.png`, `02-name.png` keeps your order.
3. Open `js/config.js` and set your Discord invite link.
4. Push to GitHub, then Settings > Pages > Deploy from a branch > main / (root).

Folder names are case sensitive on GitHub: keep `Assets` and `Portfolio` capitalised.
